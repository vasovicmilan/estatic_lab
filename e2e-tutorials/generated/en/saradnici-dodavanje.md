# Collaborators - adding and the public page

An administrator adds a collaborator (a company with its own page and an outbound link carrying the referral code), and the public “Naši saradnici” page shows it at once.

<video src="../../videos/saradnici-dodavanje/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/saradnici-dodavanje/01-admin-otvaranje-pocetne.png)

## 2. Log in

We click “Prijava”.

![admin-login-klik-prijava](../../screenshots/saradnici-dodavanje/02-admin-login-klik-prijava.png)

## 3. Admin logs in

The administrator types the email and password and logs in.

![admin-prijava](../../screenshots/saradnici-dodavanje/03-admin-prijava.png)

## 4. Open the account menu

The admin clicks the dropdown with their name in the top right corner.

![admin-ulazak-otvara-nalog-meni](../../screenshots/saradnici-dodavanje/04-admin-ulazak-otvara-nalog-meni.png)

## 5. Enter the admin panel

The admin chooses “Admin panel” from the menu, which opens the admin part of the site.

![admin-ulazak-otvara-admin-panel](../../screenshots/saradnici-dodavanje/05-admin-ulazak-otvara-admin-panel.png)

## 6. “Sadržaj i marketing” menu

We open the “Sadržaj i marketing” group.

![admin-saradnici-otvara-meni](../../screenshots/saradnici-dodavanje/06-admin-saradnici-otvara-meni.png)

## 7. Saradnici

We choose “Saradnici”.

![admin-saradnici-bira-stavku](../../screenshots/saradnici-dodavanje/07-admin-saradnici-bira-stavku.png)

## 8. New collaborator

We click “Novi saradnik”. A collaborator is a company or brand the salon works with, getting its own page on the site.

![admin-saradnici-klik-na-dodaj](../../screenshots/saradnici-dodavanje/08-admin-saradnici-klik-na-dodaj.png)

## 9. Name

We type the collaborator's name.

![saradnik-naziv](../../screenshots/saradnici-dodavanje/09-saradnik-naziv.png)

## 10. Short description

The short description is shown on the card in the collaborators list.

![saradnik-opis](../../screenshots/saradnici-dodavanje/10-saradnik-opis.png)

## 11. Cover image

The cover image is required, with alt text.

![saradnik-slika](../../screenshots/saradnici-dodavanje/11-saradnik-slika.png)

## 12. Link to the collaborator

The outbound link carrying our referral code. The app does not track it; the collaborator's platform records the sale.

![saradnik-link](../../screenshots/saradnici-dodavanje/12-saradnik-link.png)

## 13. Save

We save the collaborator. The full page content (gallery, video, text) can be added with the same editor as the blog.

![saradnik-cuvanje](../../screenshots/saradnici-dodavanje/13-saradnik-cuvanje.png)

## 14. The public site

Now we go back to the public site.

![otvaranje-pocetne](../../screenshots/saradnici-dodavanje/14-otvaranje-pocetne.png)

## 15. The “Više” menu

Less frequently used pages are grouped under “Više”. We click it to open the list.

![nav-vise-otvara](../../screenshots/saradnici-dodavanje/15-nav-vise-otvara.png)

## 16. Our collaborators

We pick “Naši saradnici” - the companies and specialists the salon works with.

![nav-saradnici](../../screenshots/saradnici-dodavanje/16-nav-saradnici.png)

## 17. The collaborator in the list

The new collaborator is already in the “Naši saradnici” list. We click its card.

![otvaranje-saradnika](../../screenshots/saradnici-dodavanje/17-otvaranje-saradnika.png)

## 18. The collaborator's page

The visitor sees the description and the button to the collaborator. The link is marked as sponsored, which is correct for search engines.

![stranica-saradnika](../../screenshots/saradnici-dodavanje/18-stranica-saradnika.png)
