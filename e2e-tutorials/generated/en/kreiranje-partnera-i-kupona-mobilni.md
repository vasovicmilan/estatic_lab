# Creating a partner and their referral coupon (phone)

The admin promotes an existing customer to a partner, sets their commission rates, and creates a referral coupon directly linked to them - every purchase through that coupon now generates commission.

<video src="../../videos/kreiranje-partnera-i-kupona-mobilni/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/kreiranje-partnera-i-kupona-mobilni/01-admin-prijava.png)

## 2. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-partnera-i-kupona-mobilni/02-admin-ulazak-otvara-nalog-meni.png)

## 3. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-partnera-i-kupona-mobilni/03-admin-ulazak-otvara-admin-panel.png)

## 4. Admin menu

The admin panel has its own menu behind a three-line button. We open it and choose the “Partnerski program” group.

![admin-partneri-otvara-meni](../../screenshots/kreiranje-partnera-i-kupona-mobilni/04-admin-partneri-otvara-meni.png)

## 5. Open the partners list

The admin taps "Partners" in the menu.

![admin-partneri-bira-stavku](../../screenshots/kreiranje-partnera-i-kupona-mobilni/05-admin-partneri-bira-stavku.png)

## 6. New partner

The admin taps "New partner".

![admin-partneri-klik-na-dodaj](../../screenshots/kreiranje-partnera-i-kupona-mobilni/06-admin-partneri-klik-na-dodaj.png)

## 7. Select the user

A partner is always made from an existing user account - the admin picks which customer to promote.

![izbor-korisnika](../../screenshots/kreiranje-partnera-i-kupona-mobilni/07-izbor-korisnika.png)

## 8. Enter commission rates

The admin enters two separate rates - for services/packages and for store products, since they rarely make sense to be the same.

![unos-provizija](../../screenshots/kreiranje-partnera-i-kupona-mobilni/08-unos-provizija.png)

## 9. Save the partner

The admin saves the new partner.

![cuvanje-partnera](../../screenshots/kreiranje-partnera-i-kupona-mobilni/09-cuvanje-partnera.png)

## 10. Admin menu

The admin panel has its own menu behind a three-line button. We open it and choose the “Prodavnica” group.

![admin-kuponi-otvara-meni](../../screenshots/kreiranje-partnera-i-kupona-mobilni/10-admin-kuponi-otvara-meni.png)

## 11. Open coupons

The admin taps "Coupons" in the menu.

![admin-kuponi-bira-stavku](../../screenshots/kreiranje-partnera-i-kupona-mobilni/11-admin-kuponi-bira-stavku.png)

## 12. New coupon

The admin taps "New coupon".

![admin-kuponi-klik-na-dodaj](../../screenshots/kreiranje-partnera-i-kupona-mobilni/12-admin-kuponi-klik-na-dodaj.png)

## 13. Enter the coupon code

The admin enters a unique coupon code.

![unos-koda-kupona](../../screenshots/kreiranje-partnera-i-kupona-mobilni/13-unos-koda-kupona.png)

## 14. Set the discount

The admin picks a discount type (percentage) and enters the value.

![unos-popusta](../../screenshots/kreiranje-partnera-i-kupona-mobilni/14-unos-popusta.png)

## 15. Link to the partner

This is what makes the coupon a referral coupon - every use now generates commission for this specific partner.

![vezivanje-za-partnera](../../screenshots/kreiranje-partnera-i-kupona-mobilni/15-vezivanje-za-partnera.png)

## 16. Save the coupon

The admin saves the coupon - the partner now has their own referral code ready to share.

![cuvanje-kupona](../../screenshots/kreiranje-partnera-i-kupona-mobilni/16-cuvanje-kupona.png)
