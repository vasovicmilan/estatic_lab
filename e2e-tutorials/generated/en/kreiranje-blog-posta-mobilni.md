# Creating a blog post (phone)

The admin writes and publishes a new blog post - a title, a short excerpt, body text through a block-based editor, and a required cover image.

<video src="../../videos/kreiranje-blog-posta-mobilni/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/kreiranje-blog-posta-mobilni/01-admin-prijava.png)

## 2. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-blog-posta-mobilni/02-admin-ulazak-otvara-nalog-meni.png)

## 3. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-blog-posta-mobilni/03-admin-ulazak-otvara-admin-panel.png)

## 4. Admin menu

The admin panel has its own menu behind a three-line button. We open it and choose the “Sadržaj i marketing” group.

![admin-blog-otvara-meni](../../screenshots/kreiranje-blog-posta-mobilni/04-admin-blog-otvara-meni.png)

## 5. Open the blog

The admin taps "Blog" in the menu.

![admin-blog-bira-stavku](../../screenshots/kreiranje-blog-posta-mobilni/05-admin-blog-bira-stavku.png)

## 6. New post

The admin taps "New post".

![admin-blog-klik-na-dodaj](../../screenshots/kreiranje-blog-posta-mobilni/06-admin-blog-klik-na-dodaj.png)

## 7. Enter the title and excerpt

The admin enters the title and a short excerpt shown in previews.

![unos-naslova-i-opisa](../../screenshots/kreiranje-blog-posta-mobilni/07-unos-naslova-i-opisa.png)

## 8. Add a paragraph

The admin adds a text block - the editor is block-based, each type has its own fields.

![dodavanje-pasusa](../../screenshots/kreiranje-blog-posta-mobilni/08-dodavanje-pasusa.png)

## 9. Choose the status

The admin selects "Published" - the post becomes publicly visible immediately.

![izbor-statusa](../../screenshots/kreiranje-blog-posta-mobilni/09-izbor-statusa.png)

## 10. Upload a cover image

A cover image is required - the admin uploads one and enters alt text.

![otpremanje-naslovne-slike](../../screenshots/kreiranje-blog-posta-mobilni/10-otpremanje-naslovne-slike.png)

## 11. Save the post

The admin saves the post - it's immediately available on the public blog.

![cuvanje-posta](../../screenshots/kreiranje-blog-posta-mobilni/11-cuvanje-posta.png)
