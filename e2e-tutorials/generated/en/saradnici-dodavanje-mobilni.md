# Collaborators - adding and the public page (phone)

An administrator adds a collaborator (a company with its own page and an outbound link carrying the referral code), and the public “Naši saradnici” page shows it at once. Recorded on a phone (390x844).

<video src="../../videos/saradnici-dodavanje-mobilni/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/saradnici-dodavanje-mobilni/01-admin-otvaranje-pocetne.png)

## 2. Open the menu

On a phone the menu is hidden behind the three-line button in the top right corner. We tap it.

![admin-login-otvara-meni](../../screenshots/saradnici-dodavanje-mobilni/02-admin-login-otvara-meni.png)

## 3. Log in

We tap “Prijava”.

![admin-login-klik-prijava](../../screenshots/saradnici-dodavanje-mobilni/03-admin-login-klik-prijava.png)

## 4. Admin logs in

The administrator types the email and password and logs in.

![admin-prijava](../../screenshots/saradnici-dodavanje-mobilni/04-admin-prijava.png)

## 5. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/saradnici-dodavanje-mobilni/05-admin-ulazak-otvara-nalog-meni.png)

## 6. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/saradnici-dodavanje-mobilni/06-admin-ulazak-otvara-admin-panel.png)

## 7. “Sadržaj i marketing” menu

We open the “Sadržaj i marketing” group.

![admin-saradnici-otvara-meni](../../screenshots/saradnici-dodavanje-mobilni/07-admin-saradnici-otvara-meni.png)

## 8. Saradnici

We choose “Saradnici”.

![admin-saradnici-bira-stavku](../../screenshots/saradnici-dodavanje-mobilni/08-admin-saradnici-bira-stavku.png)

## 9. New collaborator

We tap “Novi saradnik”. A collaborator is a company or brand the salon works with, getting its own page on the site.

![admin-saradnici-klik-na-dodaj](../../screenshots/saradnici-dodavanje-mobilni/09-admin-saradnici-klik-na-dodaj.png)

## 10. Name

We type the collaborator's name.

![saradnik-naziv](../../screenshots/saradnici-dodavanje-mobilni/10-saradnik-naziv.png)

## 11. Short description

The short description is shown on the card in the collaborators list.

![saradnik-opis](../../screenshots/saradnici-dodavanje-mobilni/11-saradnik-opis.png)

## 12. Cover image

The cover image is required, with alt text.

![saradnik-slika](../../screenshots/saradnici-dodavanje-mobilni/12-saradnik-slika.png)

## 13. Link to the collaborator

The outbound link carrying our referral code. The app does not track it; the collaborator's platform records the sale.

![saradnik-link](../../screenshots/saradnici-dodavanje-mobilni/13-saradnik-link.png)

## 14. Save

We save the collaborator. The full page content (gallery, video, text) can be added with the same editor as the blog.

![saradnik-cuvanje](../../screenshots/saradnici-dodavanje-mobilni/14-saradnik-cuvanje.png)

## 15. The public site

Now we go back to the public site.

![otvaranje-pocetne](../../screenshots/saradnici-dodavanje-mobilni/15-otvaranje-pocetne.png)

## 16. Open the menu

On a phone the menu is hidden behind the three-line button in the top right corner. We tap it.

![nav-otvara-meni](../../screenshots/saradnici-dodavanje-mobilni/16-nav-otvara-meni.png)

## 17. Our collaborators

We pick “Naši saradnici” - the companies and specialists the salon works with.

![nav-saradnici](../../screenshots/saradnici-dodavanje-mobilni/17-nav-saradnici.png)

## 18. The collaborator in the list

The new collaborator is already in the “Naši saradnici” list. We tap its card.

![otvaranje-saradnika](../../screenshots/saradnici-dodavanje-mobilni/18-otvaranje-saradnika.png)

## 19. The collaborator's page

The visitor sees the description and the button to the collaborator. The link is marked as sponsored, which is correct for search engines.

![stranica-saradnika](../../screenshots/saradnici-dodavanje-mobilni/19-stranica-saradnika.png)
