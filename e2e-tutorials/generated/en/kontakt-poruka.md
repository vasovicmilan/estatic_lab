# Contact message - from visitor to reply

A site visitor sends a message through the contact form, and an administrator finds it in “Kontakt” and marks it answered.

<video src="../../videos/kontakt-poruka/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

We start on the site's home page.

![otvaranje-pocetne](../../screenshots/kontakt-poruka/01-otvaranje-pocetne.png)

## 2. Contact

Click “Kontakt” - the message form, address and opening hours.

![nav-kontakt](../../screenshots/kontakt-poruka/02-nav-kontakt.png)

## 3. First and last name

The visitor types their first and last name.

![kontakt-ime](../../screenshots/kontakt-poruka/03-kontakt-ime.png)

## 4. Email

The reply goes to this email.

![kontakt-email](../../screenshots/kontakt-poruka/04-kontakt-email.png)

## 5. Topic and message

They type the topic and the message itself.

![kontakt-tema-poruka](../../screenshots/kontakt-poruka/05-kontakt-tema-poruka.png)

## 6. Consent

We tick that we agree with the privacy policy. The message cannot be sent without it.

![kontakt-pristanak](../../screenshots/kontakt-poruka/06-kontakt-pristanak.png)

## 7. Send the message

We click “Pošalji poruku”. The page confirms the message was sent.

![kontakt-slanje](../../screenshots/kontakt-poruka/07-kontakt-slanje.png)

## 8. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/kontakt-poruka/08-admin-otvaranje-pocetne.png)

## 9. Log in

We click “Prijava”.

![admin-login-klik-prijava](../../screenshots/kontakt-poruka/09-admin-login-klik-prijava.png)

## 10. Admin logs in

The administrator logs in.

![admin-prijava](../../screenshots/kontakt-poruka/10-admin-prijava.png)

## 11. Open the account menu

The admin clicks the dropdown with their name in the top right corner.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kontakt-poruka/11-admin-ulazak-otvara-nalog-meni.png)

## 12. Enter the admin panel

The admin chooses “Admin panel” from the menu, which opens the admin part of the site.

![admin-ulazak-otvara-admin-panel](../../screenshots/kontakt-poruka/12-admin-ulazak-otvara-admin-panel.png)

## 13. “Content and marketing” menu

We open the “Sadržaj i marketing” group.

![admin-kontakt-otvara-meni](../../screenshots/kontakt-poruka/13-admin-kontakt-otvara-meni.png)

## 14. Contact messages

We choose “Kontakt” - the list of all messages from the site.

![admin-kontakt-bira-stavku](../../screenshots/kontakt-poruka/14-admin-kontakt-bira-stavku.png)

## 15. Find the message

We find the message by email, name or topic.

![admin-kontakt-pretraga](../../screenshots/kontakt-poruka/15-admin-kontakt-pretraga.png)

## 16. Message details

We open the message and read it.

![admin-kontakt-otvaranje-rezultata](../../screenshots/kontakt-poruka/16-admin-kontakt-otvaranje-rezultata.png)

## 17. Message status

After replying, we set the status to “Odgovoren” so it is clear what is still waiting.

![admin-kontakt-status](../../screenshots/kontakt-poruka/17-admin-kontakt-status.png)
