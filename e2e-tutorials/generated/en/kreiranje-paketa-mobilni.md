# Creating a package (phone)

The admin creates a new session package - selecting an existing service, entering a price, and setting a required image, all before the package is ready to be assigned to customers.

<video src="../../videos/kreiranje-paketa-mobilni/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/kreiranje-paketa-mobilni/01-admin-prijava.png)

## 2. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-paketa-mobilni/02-admin-ulazak-otvara-nalog-meni.png)

## 3. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-paketa-mobilni/03-admin-ulazak-otvara-admin-panel.png)

## 4. Admin menu

The admin panel has its own menu behind a three-line button. We open it and choose the “Katalog” group.

![admin-paketi-otvara-meni](../../screenshots/kreiranje-paketa-mobilni/04-admin-paketi-otvara-meni.png)

## 5. Open packages

The admin taps "Packages" in the menu.

![admin-paketi-bira-stavku](../../screenshots/kreiranje-paketa-mobilni/05-admin-paketi-bira-stavku.png)

## 6. New package

The admin taps "New package".

![admin-paketi-klik-na-dodaj](../../screenshots/kreiranje-paketa-mobilni/06-admin-paketi-klik-na-dodaj.png)

## 7. Enter basic details

The admin enters the package's name and description.

![unos-osnovnih-podataka](../../screenshots/kreiranje-paketa-mobilni/07-unos-osnovnih-podataka.png)

## 8. Add a service to the package

The admin adds a row, picks the exact service and variant, and enters how many sessions the package includes.

![dodavanje-usluge-u-paket](../../screenshots/kreiranje-paketa-mobilni/08-dodavanje-usluge-u-paket.png)

## 9. Enter the price

The admin enters the package's total price - usually lower than the sum of individual sessions.

![unos-cene](../../screenshots/kreiranje-paketa-mobilni/09-unos-cene.png)

## 10. Upload an image

An image is required for a package - the admin uploads one and enters alt text.

![otpremanje-slike](../../screenshots/kreiranje-paketa-mobilni/10-otpremanje-slike.png)

## 11. Save the package

The admin saves the package - it's now ready to be assigned to customers.

![cuvanje-paketa](../../screenshots/kreiranje-paketa-mobilni/11-cuvanje-paketa.png)
