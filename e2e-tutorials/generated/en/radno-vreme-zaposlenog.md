# Employee working hours

How an employee sets their own working hours, and how that immediately affects which appointment slots are available for booking.

<video src="../../videos/radno-vreme-zaposlenog/merged.en.burned.webm" controls width="720"></video>

_titl je zapečen u video - ne treba spoljni .vtt fajl_

## 1. No working hours, no slots

While the employee has no working hours set for a given day, the customer sees no available slots on the booking page.

![bez-radnog-vremena-nema-termina](../../screenshots/radno-vreme-zaposlenog/01-bez-radnog-vremena-nema-termina.png)

## 2. Employee logs in

The employee logs into their own account to set up working hours.

![prijava-zaposlenog](../../screenshots/radno-vreme-zaposlenog/02-prijava-zaposlenog.png)

## 3. Open the profile page

On the profile page, the employee sees a weekly schedule, day by day.

![otvaranje-profila](../../screenshots/radno-vreme-zaposlenog/03-otvaranje-profila.png)

## 4. Add a working window

The employee adds a time window for the day (e.g. 09:00-17:00) via the interactive schedule widget.

![dodavanje-radnog-vremena](../../screenshots/radno-vreme-zaposlenog/04-dodavanje-radnog-vremena.png)

## 5. Save working hours

Clicking "Save working hours" saves the change.

![cuvanje-radnog-vremena](../../screenshots/radno-vreme-zaposlenog/05-cuvanje-radnog-vremena.png)

## 6. Slots are now available

The same booking page, with no further change from the customer's side, now shows available slots within the new working hours.

![termini-sada-dostupni](../../screenshots/radno-vreme-zaposlenog/06-termini-sada-dostupni.png)
