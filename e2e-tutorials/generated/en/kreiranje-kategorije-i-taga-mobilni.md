# Creating a category and a tag (phone)

An administrator groups the catalog: creates a category (with a required image) and a tag, through the menus. Recorded on a phone (390x844).

<video src="../../videos/kreiranje-kategorije-i-taga-mobilni/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/kreiranje-kategorije-i-taga-mobilni/01-admin-otvaranje-pocetne.png)

## 2. Open the menu

On a phone the menu is hidden behind the three-line button in the top right corner. We tap it.

![admin-login-otvara-meni](../../screenshots/kreiranje-kategorije-i-taga-mobilni/02-admin-login-otvara-meni.png)

## 3. Log in

We tap “Prijava”.

![admin-login-klik-prijava](../../screenshots/kreiranje-kategorije-i-taga-mobilni/03-admin-login-klik-prijava.png)

## 4. Admin logs in

The administrator types the email and password and logs in.

![admin-prijava](../../screenshots/kreiranje-kategorije-i-taga-mobilni/04-admin-prijava.png)

## 5. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-kategorije-i-taga-mobilni/05-admin-ulazak-otvara-nalog-meni.png)

## 6. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-kategorije-i-taga-mobilni/06-admin-ulazak-otvara-admin-panel.png)

## 7. “Katalog” menu

We open the “Katalog” group.

![admin-kategorije-otvara-meni](../../screenshots/kreiranje-kategorije-i-taga-mobilni/07-admin-kategorije-otvara-meni.png)

## 8. Kategorije

We choose “Kategorije”.

![admin-kategorije-bira-stavku](../../screenshots/kreiranje-kategorije-i-taga-mobilni/08-admin-kategorije-bira-stavku.png)

## 9. New category

We tap “Nova kategorija”. Categories group services, products and posts and create archive pages on the site.

![admin-kategorije-klik-na-dodaj](../../screenshots/kreiranje-kategorije-i-taga-mobilni/09-admin-kategorije-klik-na-dodaj.png)

## 10. Category name

We type the name. The address (slug) is generated from it.

![kategorija-naziv](../../screenshots/kreiranje-kategorije-i-taga-mobilni/10-kategorija-naziv.png)

## 11. Domain

The domain says what the category is for: services, products or the blog.

![kategorija-domen](../../screenshots/kreiranje-kategorije-i-taga-mobilni/11-kategorija-domen.png)

## 12. Short description

The short description appears on the category archive and in search results.

![kategorija-opis](../../screenshots/kreiranje-kategorije-i-taga-mobilni/12-kategorija-opis.png)

## 13. Category image

The image is required, and the alt text describes it for screen readers and search.

![kategorija-slika](../../screenshots/kreiranje-kategorije-i-taga-mobilni/13-kategorija-slika.png)

## 14. Save the category

We save the category.

![kategorija-cuvanje](../../screenshots/kreiranje-kategorije-i-taga-mobilni/14-kategorija-cuvanje.png)

## 15. “Katalog” menu

We open the “Katalog” group.

![admin-tagovi-otvara-meni](../../screenshots/kreiranje-kategorije-i-taga-mobilni/15-admin-tagovi-otvara-meni.png)

## 16. Tagovi

We choose “Tagovi”.

![admin-tagovi-bira-stavku](../../screenshots/kreiranje-kategorije-i-taga-mobilni/16-admin-tagovi-bira-stavku.png)

## 17. New tag

We tap “Novi tag”. Tags are finer labels than categories, linking related content.

![admin-tagovi-klik-na-dodaj](../../screenshots/kreiranje-kategorije-i-taga-mobilni/17-admin-tagovi-klik-na-dodaj.png)

## 18. Tag name

A tag only needs a name.

![tag-naziv](../../screenshots/kreiranje-kategorije-i-taga-mobilni/18-tag-naziv.png)

## 19. Save the tag

We save the tag; it can now be assigned to services, products and posts.

![tag-cuvanje](../../screenshots/kreiranje-kategorije-i-taga-mobilni/19-tag-cuvanje.png)
