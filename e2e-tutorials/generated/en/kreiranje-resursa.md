# Creating a resource

An administrator adds a resource (a device or table) that appointments reserve: name, capacity and a note, all through the menus.

<video src="../../videos/kreiranje-resursa/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/kreiranje-resursa/01-admin-otvaranje-pocetne.png)

## 2. Log in

We click “Prijava”.

![admin-login-klik-prijava](../../screenshots/kreiranje-resursa/02-admin-login-klik-prijava.png)

## 3. Admin logs in

The administrator types the email and password and logs in.

![admin-prijava](../../screenshots/kreiranje-resursa/03-admin-prijava.png)

## 4. Open the account menu

The admin clicks the dropdown with their name in the top right corner.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-resursa/04-admin-ulazak-otvara-nalog-meni.png)

## 5. Enter the admin panel

The admin chooses “Admin panel” from the menu, which opens the admin part of the site.

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-resursa/05-admin-ulazak-otvara-admin-panel.png)

## 6. “Zakazivanje” menu

We open the “Zakazivanje” group.

![admin-resursi-otvara-meni](../../screenshots/kreiranje-resursa/06-admin-resursi-otvara-meni.png)

## 7. Resursi

We choose “Resursi”.

![admin-resursi-bira-stavku](../../screenshots/kreiranje-resursa/07-admin-resursi-bira-stavku.png)

## 8. New resource

We click “Novi resurs”. A resource is a device or table an appointment reserves - while it is in use, no other appointment can exceed its capacity.

![admin-resursi-klik-na-dodaj](../../screenshots/kreiranje-resursa/08-admin-resursi-klik-na-dodaj.png)

## 9. Name

We type the resource's name, e.g. the name of a device.

![unos-naziva](../../screenshots/kreiranje-resursa/09-unos-naziva.png)

## 10. Capacity

Capacity is how many appointments can use the resource at the same time. Here there are two devices of the same type, so the capacity is 2.

![unos-kapaciteta](../../screenshots/kreiranje-resursa/10-unos-kapaciteta.png)

## 11. Note

The note is internal and only staff see it.

![unos-napomene](../../screenshots/kreiranje-resursa/11-unos-napomene.png)

## 12. Save

We save the resource. When all its capacity is taken at some time, the system stops offering services that need it.

![cuvanje-resursa](../../screenshots/kreiranje-resursa/12-cuvanje-resursa.png)
