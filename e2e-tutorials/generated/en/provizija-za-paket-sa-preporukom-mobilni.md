# Commission on a package bought via a partner referral (phone)

When a package is bought through a partner's referral code, two discounts combine: the partner's coupon and the package's own built-in discount. The system has to correctly calculate commission for both the partner (based on what was actually paid) and the employee (proportional to the service's true, undiscounted value) - this is a real business rule from the internal docs, not a made-up example. Recorded on a phone (390x844).

## 27. Admin completes the appointment

The admin confirms then completes the appointment - this is when the employee's commission is calculated. The base is correctly proportional to the combined discount (2160); at a 10% rate that would be 216. Because the session was paid from a package, the employee has a guaranteed per-session minimum (500 by default, set in “Podešavanja sajta”), so the higher amount is recorded.
