# Site settings - booking policy and currency

An administrator changes the gap between appointments, the cancellation deadline and the currency display in “Podešavanja sajta”, with no code change and no restart.

<video src="../../videos/podesavanja-sajta/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/podesavanja-sajta/01-admin-otvaranje-pocetne.png)

## 2. Log in

We click “Prijava”.

![admin-login-klik-prijava](../../screenshots/podesavanja-sajta/02-admin-login-klik-prijava.png)

## 3. Admin logs in

The administrator types the email and password and logs in.

![admin-prijava](../../screenshots/podesavanja-sajta/03-admin-prijava.png)

## 4. Open the account menu

The admin clicks the dropdown with their name in the top right corner.

![admin-ulazak-otvara-nalog-meni](../../screenshots/podesavanja-sajta/04-admin-ulazak-otvara-nalog-meni.png)

## 5. Enter the admin panel

The admin chooses “Admin panel” from the menu, which opens the admin part of the site.

![admin-ulazak-otvara-admin-panel](../../screenshots/podesavanja-sajta/05-admin-ulazak-otvara-admin-panel.png)

## 6. “Sadržaj i marketing” menu

We open the “Sadržaj i marketing” group.

![admin-sajt-otvara-meni](../../screenshots/podesavanja-sajta/06-admin-sajt-otvara-meni.png)

## 7. Podešavanja sajta

We choose “Podešavanja sajta”.

![admin-sajt-bira-stavku](../../screenshots/podesavanja-sajta/07-admin-sajt-bira-stavku.png)

## 8. Gap between appointments

The booking policy is data, not code. We change the gap between appointments here, e.g. to 45 minutes.

![sajt-politika-zakazivanja](../../screenshots/podesavanja-sajta/08-sajt-politika-zakazivanja.png)

## 9. Cancellation deadline

The deadline until which a client may cancel their own appointment, e.g. 12 hours ahead.

![sajt-otkazivanje](../../screenshots/podesavanja-sajta/09-sajt-otkazivanje.png)

## 10. Currency display

The currency label changes only how a price is displayed, not the amounts in the database.

![sajt-valuta](../../screenshots/podesavanja-sajta/10-sajt-valuta.png)

## 11. Save

We save. The change is effective at once, with no server restart.

![sajt-cuvanje](../../screenshots/podesavanja-sajta/11-sajt-cuvanje.png)
