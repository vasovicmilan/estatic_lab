# Contact message - from visitor to reply (phone)

A site visitor sends a message through the contact form, and an administrator finds it in “Kontakt” and marks it answered. Recorded on a phone (390x844).

<video src="../../videos/kontakt-poruka-mobilni/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

We start on the site's home page.

![otvaranje-pocetne](../../screenshots/kontakt-poruka-mobilni/01-otvaranje-pocetne.png)

## 2. Open the menu

On a phone the menu is hidden behind the three-line button in the top right corner. We tap it.

![nav-otvara-meni](../../screenshots/kontakt-poruka-mobilni/02-nav-otvara-meni.png)

## 3. Contact

Tap “Kontakt” - the message form, address and opening hours.

![nav-kontakt](../../screenshots/kontakt-poruka-mobilni/03-nav-kontakt.png)

## 4. First and last name

The visitor types their first and last name.

![kontakt-ime](../../screenshots/kontakt-poruka-mobilni/04-kontakt-ime.png)

## 5. Email

The reply goes to this email.

![kontakt-email](../../screenshots/kontakt-poruka-mobilni/05-kontakt-email.png)

## 6. Topic and message

They type the topic and the message itself.

![kontakt-tema-poruka](../../screenshots/kontakt-poruka-mobilni/06-kontakt-tema-poruka.png)

## 7. Consent

We tick that we agree with the privacy policy. The message cannot be sent without it.

![kontakt-pristanak](../../screenshots/kontakt-poruka-mobilni/07-kontakt-pristanak.png)

## 8. Send the message

We tap “Pošalji poruku”. The page confirms the message was sent.

![kontakt-slanje](../../screenshots/kontakt-poruka-mobilni/08-kontakt-slanje.png)

## 9. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/kontakt-poruka-mobilni/09-admin-otvaranje-pocetne.png)

## 10. Open the menu

On a phone the menu is hidden behind the three-line button in the top right corner. We tap it.

![admin-login-otvara-meni](../../screenshots/kontakt-poruka-mobilni/10-admin-login-otvara-meni.png)

## 11. Log in

We tap “Prijava”.

![admin-login-klik-prijava](../../screenshots/kontakt-poruka-mobilni/11-admin-login-klik-prijava.png)

## 12. Admin logs in

The administrator logs in.

![admin-prijava](../../screenshots/kontakt-poruka-mobilni/12-admin-prijava.png)

## 13. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kontakt-poruka-mobilni/13-admin-ulazak-otvara-nalog-meni.png)

## 14. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/kontakt-poruka-mobilni/14-admin-ulazak-otvara-admin-panel.png)

## 15. “Content and marketing” menu

We open the “Sadržaj i marketing” group.

![admin-kontakt-otvara-meni](../../screenshots/kontakt-poruka-mobilni/15-admin-kontakt-otvara-meni.png)

## 16. Contact messages

We choose “Kontakt” - the list of all messages from the site.

![admin-kontakt-bira-stavku](../../screenshots/kontakt-poruka-mobilni/16-admin-kontakt-bira-stavku.png)

## 17. Find the message

We find the message by email, name or topic.

![admin-kontakt-pretraga](../../screenshots/kontakt-poruka-mobilni/17-admin-kontakt-pretraga.png)

## 18. Message details

We open the message and read it.

![admin-kontakt-otvaranje-rezultata](../../screenshots/kontakt-poruka-mobilni/18-admin-kontakt-otvaranje-rezultata.png)

## 19. Message status

After replying, we set the status to “Odgovoren” so it is clear what is still waiting.

![admin-kontakt-status](../../screenshots/kontakt-poruka-mobilni/19-admin-kontakt-status.png)
