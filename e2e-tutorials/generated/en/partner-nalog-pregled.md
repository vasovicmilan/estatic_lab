# Partner account - overview, copying your code and the catalog

On their account a partner sees how much they've earned, copies their referral link, reviews their commission and grabs ready-made links for every service, package and product from the sharing catalog. Every navigation step is shown.

<video src="../../videos/partner-nalog-pregled/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

We start on the site's home page.

![otvaranje-pocetne](../../screenshots/partner-nalog-pregled/01-otvaranje-pocetne.png)

## 2. Log in

In the top right corner we click “Prijava”.

![login-klik-prijava](../../screenshots/partner-nalog-pregled/02-login-klik-prijava.png)

## 3. Enter your login details

We enter the email and password and log in.

![unos-prijave](../../screenshots/partner-nalog-pregled/03-unos-prijave.png)

## 4. Account menu

After logging in our name appears in the top right corner. Clicking it opens the account menu.

![portal-otvara-meni](../../screenshots/partner-nalog-pregled/04-portal-otvara-meni.png)

## 5. Partner account

In the menu we choose “Partnerski nalog”.

![portal-bira-stavku](../../screenshots/partner-nalog-pregled/05-portal-bira-stavku.png)

## 6. Partner account

“Moj partnerski nalog” opens. At the top it shows the commission rate on services and packages, and the one on shop products.

![otvaranje-partnerskog-naloga](../../screenshots/partner-nalog-pregled/06-otvaranje-partnerskog-naloga.png)

## 7. Balance overview

Four cards: total earned, paid out, reserved (commission pending until the appointment or order is completed) and available for payout. Only earned commission can be paid out.

![pregled-stanja](../../screenshots/partner-nalog-pregled/07-pregled-stanja.png)

## 8. Referral link

Here is the partner's referral link with their code, along with the discount the customer gets and what the code covers. If a partner has several codes, each has its own link.

![referalni-link](../../screenshots/partner-nalog-pregled/08-referalni-link.png)

## 9. Copy the link

The “Kopiraj” button copies the link and briefly shows “Kopirano!”. Whenever someone visits the site through that link, the code is applied automatically.

![kopiranje-linka](../../screenshots/partner-nalog-pregled/09-kopiranje-linka.png)

## 10. Commission tab

Clicking “Provizija” in the top bar switches to that tab. It lists every commission.

![tab-provizija](../../screenshots/partner-nalog-pregled/10-tab-provizija.png)

## 11. Commission list

For each commission we see the source (appointment, package or order), base value, rate, amount and status.

![pregled-provizije](../../screenshots/partner-nalog-pregled/11-pregled-provizije.png)

## 12. Filtering

Filters by status and source update the list as soon as a value is chosen. “Na čekanju” shows commission that isn't earned yet.

![filter-provizije](../../screenshots/partner-nalog-pregled/12-filter-provizije.png)

## 13. Sharing catalog

Clicking “Katalog” in the top bar switches to that tab. It lists services, packages and products, each with a ready link that already contains the partner's code.

![tab-katalog](../../screenshots/partner-nalog-pregled/13-tab-katalog.png)

## 14. Searching the catalog

Search finds an item by name across all three sections at once.

![pretraga-kataloga](../../screenshots/partner-nalog-pregled/14-pretraga-kataloga.png)

## 15. Copy an item's link

The link goes straight to that service or package with the code already applied. It's copied with the same button as the main link.

![kopiranje-iz-kataloga](../../screenshots/partner-nalog-pregled/15-kopiranje-iz-kataloga.png)

## 16. Products in the catalog

Products only appear if the code includes a shop-product discount, and only those the code actually applies to. That way a partner never shares a link that wouldn't give a discount.

![proizvodi-u-katalogu](../../screenshots/partner-nalog-pregled/16-proizvodi-u-katalogu.png)

## 17. Payouts tab

Clicking “Isplate” in the top bar switches to that tab. Here the partner sees all their payout requests. There are none yet.

![tab-isplate](../../screenshots/partner-nalog-pregled/17-tab-isplate.png)

## 18. Back to overview

Clicking “Pregled” in the top bar switches to that tab. That takes us back to the account's main screen.

![tab-pregled](../../screenshots/partner-nalog-pregled/18-tab-pregled.png)
