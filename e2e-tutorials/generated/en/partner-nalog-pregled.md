# Partner account - overview, copying your code and the catalog

On their account a partner sees how much they've earned, copies their referral link, reviews their commission and grabs ready-made links for every service, package and product from the sharing catalog.

## 1. Partner logs in

The partner logs into their account.

![prijava-partnera](../../screenshots/partner-nalog-pregled/01-prijava-partnera.png)

## 2. Partner account

The “Moj partnerski nalog” page opens. At the top it shows the commission rate on services and packages, and the one on shop products.

![otvaranje-partnerskog-naloga](../../screenshots/partner-nalog-pregled/02-otvaranje-partnerskog-naloga.png)

## 3. Balance overview

Four cards: total earned, paid out, reserved (commission pending until the appointment or order is completed) and available for payout. Only earned commission can be paid out.

![pregled-stanja](../../screenshots/partner-nalog-pregled/03-pregled-stanja.png)

## 4. Referral link

Here is the partner's referral link with their code, along with the discount the customer gets and what the code covers. If a partner has several codes, each has its own link.

![referalni-link](../../screenshots/partner-nalog-pregled/04-referalni-link.png)

## 5. Copy the link

The “Kopiraj” button copies the link and briefly shows “Kopirano!”. Whenever someone visits the site through that link, the code is applied automatically.

![kopiranje-linka](../../screenshots/partner-nalog-pregled/05-kopiranje-linka.png)

## 6. Commission list

The “Provizija” tab lists every commission: source (appointment, package or order), base value, rate and amount.

![pregled-provizije](../../screenshots/partner-nalog-pregled/06-pregled-provizije.png)

## 7. Filtering

Filters by status and source update the list as soon as a value is chosen. “Na čekanju” shows commission that isn't earned yet.

![filter-provizije](../../screenshots/partner-nalog-pregled/07-filter-provizije.png)

## 8. Sharing catalog

The “Katalog” tab lists services, packages and products, each with a ready link that already contains the partner's code - nothing to add manually.

![otvaranje-kataloga](../../screenshots/partner-nalog-pregled/08-otvaranje-kataloga.png)

## 9. Searching the catalog

Search finds an item by name across all three sections at once.

![pretraga-kataloga](../../screenshots/partner-nalog-pregled/09-pretraga-kataloga.png)

## 10. Copy an item's link

The link goes straight to that service or package with the code already applied. It's copied with the same button as the main link.

![kopiranje-iz-kataloga](../../screenshots/partner-nalog-pregled/10-kopiranje-iz-kataloga.png)

## 11. Products in the catalog

Products only appear if the code includes a shop-product discount, and only those the code actually applies to. That way a partner never shares a link that wouldn't give a discount.

![proizvodi-u-katalogu](../../screenshots/partner-nalog-pregled/11-proizvodi-u-katalogu.png)
