# Creating a product (phone)

Adding a product goes through three separate phases - basic details, then variations and images, then shipping and publishing. Each phase is its own page and its own save, not one long form.

<video src="../../videos/kreiranje-proizvoda-mobilni/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/kreiranje-proizvoda-mobilni/01-admin-prijava.png)

## 2. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-proizvoda-mobilni/02-admin-ulazak-otvara-nalog-meni.png)

## 3. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-proizvoda-mobilni/03-admin-ulazak-otvara-admin-panel.png)

## 4. Admin menu

The admin panel has its own menu behind a three-line button. We open it and choose the “Prodavnica” group.

![admin-proizvodi-otvara-meni](../../screenshots/kreiranje-proizvoda-mobilni/04-admin-proizvodi-otvara-meni.png)

## 5. Open products

The admin taps "Products" in the menu.

![admin-proizvodi-bira-stavku](../../screenshots/kreiranje-proizvoda-mobilni/05-admin-proizvodi-bira-stavku.png)

## 6. New product

The admin taps "New product" - starting the three-phase wizard.

![admin-proizvodi-klik-na-dodaj](../../screenshots/kreiranje-proizvoda-mobilni/06-admin-proizvodi-klik-na-dodaj.png)

## 7. Phase 1: name and SKU

The first phase asks for only the bare minimum for the product to exist at all - a name and a unique SKU.

![faza1-naziv-i-sku](../../screenshots/kreiranje-proizvoda-mobilni/07-faza1-naziv-i-sku.png)

## 8. Move to phase 2

The admin saves and continues - the product is created as a draft, next come variations and an image.

![faza1-nastavak](../../screenshots/kreiranje-proizvoda-mobilni/08-faza1-nastavak.png)

## 9. Phase 2: short description

The admin enters a short description shown on the product card.

![faza2-kratak-opis](../../screenshots/kreiranje-proizvoda-mobilni/09-faza2-kratak-opis.png)

## 10. Add a variation

A product needs at least one variation to be publishable - the admin enters a name, price, and stock.

![faza2-dodavanje-varijante](../../screenshots/kreiranje-proizvoda-mobilni/10-faza2-dodavanje-varijante.png)

## 11. Upload the main image

An image is required for the product to be publishable in the third phase.

![faza2-otpremanje-slike](../../screenshots/kreiranje-proizvoda-mobilni/11-faza2-otpremanje-slike.png)

## 12. Move to phase 3

The admin saves and continues to the final phase.

![faza2-nastavak](../../screenshots/kreiranje-proizvoda-mobilni/12-faza2-nastavak.png)

## 13. Phase 3: shipping method

The admin picks a shipping method - "regular post" for most items, or the option for large/heavy devices where shipping is priced manually.

![faza3-nacin-dostave](../../screenshots/kreiranje-proizvoda-mobilni/13-faza3-nacin-dostave.png)

## 14. Publish

The admin saves the final phase - the product is immediately published and visible in the store.

![faza3-objavljivanje](../../screenshots/kreiranje-proizvoda-mobilni/14-faza3-objavljivanje.png)
