# Creating a partner and their referral coupon

The admin promotes an existing customer to a partner, sets their commission rates, and creates a referral coupon directly linked to them - every purchase through that coupon now generates commission.

<video src="../../videos/kreiranje-partnera-i-kupona/merged.en.burned.webm" controls width="720"></video>

_titl je zapečen u video - ne treba spoljni .vtt fajl_

## 1. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/kreiranje-partnera-i-kupona/01-admin-prijava.png)

## 2. Open the account menu

The admin clicks the dropdown showing their name.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-partnera-i-kupona/02-admin-ulazak-otvara-nalog-meni.png)

## 3. Enter the admin panel

The admin picks "Admin panel".

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-partnera-i-kupona/03-admin-ulazak-otvara-admin-panel.png)

## 4. Open the "Partner program" menu

The admin clicks the "Partner program" group.

![admin-partneri-otvara-meni](../../screenshots/kreiranje-partnera-i-kupona/04-admin-partneri-otvara-meni.png)

## 5. Open the partners list

The admin picks "Partners" from the menu.

![admin-partneri-bira-stavku](../../screenshots/kreiranje-partnera-i-kupona/05-admin-partneri-bira-stavku.png)

## 6. New partner

The admin clicks "New partner".

![admin-partneri-klik-na-dodaj](../../screenshots/kreiranje-partnera-i-kupona/06-admin-partneri-klik-na-dodaj.png)

## 7. Select the user

A partner is always made from an existing user account - the admin picks which customer to promote.

![izbor-korisnika](../../screenshots/kreiranje-partnera-i-kupona/07-izbor-korisnika.png)

## 8. Enter commission rates

The admin enters two separate rates - for services/packages and for store products, since they rarely make sense to be the same.

![unos-provizija](../../screenshots/kreiranje-partnera-i-kupona/08-unos-provizija.png)

## 9. Save the partner

The admin saves the new partner.

![cuvanje-partnera](../../screenshots/kreiranje-partnera-i-kupona/09-cuvanje-partnera.png)

## 10. Open the "Store" menu

The admin clicks the "Store" group.

![admin-kuponi-otvara-meni](../../screenshots/kreiranje-partnera-i-kupona/10-admin-kuponi-otvara-meni.png)

## 11. Open coupons

The admin picks "Coupons" from the menu.

![admin-kuponi-bira-stavku](../../screenshots/kreiranje-partnera-i-kupona/11-admin-kuponi-bira-stavku.png)

## 12. New coupon

The admin clicks "New coupon".

![admin-kuponi-klik-na-dodaj](../../screenshots/kreiranje-partnera-i-kupona/12-admin-kuponi-klik-na-dodaj.png)

## 13. Enter the coupon code

The admin enters a unique coupon code.

![unos-koda-kupona](../../screenshots/kreiranje-partnera-i-kupona/13-unos-koda-kupona.png)

## 14. Set the discount

The admin picks a discount type (percentage) and enters the value.

![unos-popusta](../../screenshots/kreiranje-partnera-i-kupona/14-unos-popusta.png)

## 15. Link to the partner

This is what makes the coupon a referral coupon - every use now generates commission for this specific partner.

![vezivanje-za-partnera](../../screenshots/kreiranje-partnera-i-kupona/15-vezivanje-za-partnera.png)

## 16. Save the coupon

The admin saves the coupon - the partner now has their own referral code ready to share.

![cuvanje-kupona](../../screenshots/kreiranje-partnera-i-kupona/16-cuvanje-kupona.png)
