# Creating a resource (phone)

An administrator adds a resource (a device or table) that appointments reserve: name, capacity and a note, all through the menus. Recorded on a phone (390x844).

<video src="../../videos/kreiranje-resursa-mobilni/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/kreiranje-resursa-mobilni/01-admin-otvaranje-pocetne.png)

## 2. Open the menu

On a phone the menu is hidden behind the three-line button in the top right corner. We tap it.

![admin-login-otvara-meni](../../screenshots/kreiranje-resursa-mobilni/02-admin-login-otvara-meni.png)

## 3. Log in

We tap “Prijava”.

![admin-login-klik-prijava](../../screenshots/kreiranje-resursa-mobilni/03-admin-login-klik-prijava.png)

## 4. Admin logs in

The administrator types the email and password and logs in.

![admin-prijava](../../screenshots/kreiranje-resursa-mobilni/04-admin-prijava.png)

## 5. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-resursa-mobilni/05-admin-ulazak-otvara-nalog-meni.png)

## 6. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-resursa-mobilni/06-admin-ulazak-otvara-admin-panel.png)

## 7. “Zakazivanje” menu

We open the “Zakazivanje” group.

![admin-resursi-otvara-meni](../../screenshots/kreiranje-resursa-mobilni/07-admin-resursi-otvara-meni.png)

## 8. Resursi

We choose “Resursi”.

![admin-resursi-bira-stavku](../../screenshots/kreiranje-resursa-mobilni/08-admin-resursi-bira-stavku.png)

## 9. New resource

We tap “Novi resurs”. A resource is a device or table an appointment reserves - while it is in use, no other appointment can exceed its capacity.

![admin-resursi-klik-na-dodaj](../../screenshots/kreiranje-resursa-mobilni/09-admin-resursi-klik-na-dodaj.png)

## 10. Name

We type the resource's name, e.g. the name of a device.

![unos-naziva](../../screenshots/kreiranje-resursa-mobilni/10-unos-naziva.png)

## 11. Capacity

Capacity is how many appointments can use the resource at the same time. Here there are two devices of the same type, so the capacity is 2.

![unos-kapaciteta](../../screenshots/kreiranje-resursa-mobilni/11-unos-kapaciteta.png)

## 12. Note

The note is internal and only staff see it.

![unos-napomene](../../screenshots/kreiranje-resursa-mobilni/12-unos-napomene.png)

## 13. Save

We save the resource. When all its capacity is taken at some time, the system stops offering services that need it.

![cuvanje-resursa](../../screenshots/kreiranje-resursa-mobilni/13-cuvanje-resursa.png)
