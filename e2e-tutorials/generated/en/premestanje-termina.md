# Reassigning an appointment

An admin can move an appointment to a different employee. The system filters the list itself - an employee already busy at that time simply doesn't appear as an option, instead of being offered and then rejected.

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/premestanje-termina/01-admin-otvaranje-pocetne.png)

## 2. Log in

We click “Prijava”.

![admin-login-klik-prijava](../../screenshots/premestanje-termina/02-admin-login-klik-prijava.png)

## 3. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/premestanje-termina/03-admin-prijava.png)

## 4. Open the account menu

The admin clicks the dropdown with their name in the top right corner.

![admin-ulazak-otvara-nalog-meni](../../screenshots/premestanje-termina/04-admin-ulazak-otvara-nalog-meni.png)

## 5. Enter the admin panel

The admin chooses “Admin panel” from the menu, which opens the admin part of the site.

![admin-ulazak-otvara-admin-panel](../../screenshots/premestanje-termina/05-admin-ulazak-otvara-admin-panel.png)

## 6. Open the "Scheduling" menu

The admin clicks the "Scheduling" group in the admin menu.

![admin-termini-otvara-meni](../../screenshots/premestanje-termina/06-admin-termini-otvara-meni.png)

## 7. Open the appointments list

The admin picks "Appointments" from the menu.

![admin-termini-bira-stavku](../../screenshots/premestanje-termina/07-admin-termini-bira-stavku.png)

## 8. Search for the appointment

The admin searches the list by the customer's email to find the appointment that needs to move.

![admin-termini-pretraga](../../screenshots/premestanje-termina/08-admin-termini-pretraga.png)

## 9. Open the appointment

The admin opens the appointment's details.

![admin-termini-otvaranje-rezultata](../../screenshots/premestanje-termina/09-admin-termini-otvaranje-rezultata.png)

## 10. Reassign to a free employee

The admin picks a free employee from the dropdown and confirms the change.

![premestanje-na-slobodnog](../../screenshots/premestanje-termina/10-premestanje-na-slobodnog.png)

## 11. Reopen the menu

The admin returns to the menu to check the appointment once more.

![admin-ponovo-otvara-meni](../../screenshots/premestanje-termina/11-admin-ponovo-otvara-meni.png)

## 12. Reopen the appointments list

The admin opens the appointments list again.

![admin-ponovo-bira-stavku](../../screenshots/premestanje-termina/12-admin-ponovo-bira-stavku.png)

## 13. Search again

The admin searches for the same customer again.

![admin-ponovo-pretraga](../../screenshots/premestanje-termina/13-admin-ponovo-pretraga.png)

## 14. Reopen the appointment

The admin reopens the same appointment, this time to check the assignment dropdown.

![admin-ponovo-otvaranje-rezultata](../../screenshots/premestanje-termina/14-admin-ponovo-otvaranje-rezultata.png)

## 15. A busy employee isn't offered

In the dropdown, an employee already booked elsewhere at that exact time simply isn't listed - the system filtered them out in advance.

![zauzet-zaposleni-nije-ponudjen](../../screenshots/premestanje-termina/15-zauzet-zaposleni-nije-ponudjen.png)
