# Reassigning an appointment (phone)

An admin can move an appointment to a different employee. The system filters the list itself - an employee already busy at that time simply doesn't appear as an option, instead of being offered and then rejected. Recorded on a phone (390x844).

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/premestanje-termina-mobilni/01-admin-otvaranje-pocetne.png)

## 2. Open the menu

On a phone the menu is hidden behind the three-line button in the top right corner. We tap it.

![admin-login-otvara-meni](../../screenshots/premestanje-termina-mobilni/02-admin-login-otvara-meni.png)

## 3. Log in

We tap “Prijava”.

![admin-login-klik-prijava](../../screenshots/premestanje-termina-mobilni/03-admin-login-klik-prijava.png)

## 4. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/premestanje-termina-mobilni/04-admin-prijava.png)

## 5. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/premestanje-termina-mobilni/05-admin-ulazak-otvara-nalog-meni.png)

## 6. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/premestanje-termina-mobilni/06-admin-ulazak-otvara-admin-panel.png)

## 7. Open the "Scheduling" menu

The admin panel has its own menu behind a three-line button. The admin opens it and chooses the “Scheduling” group.

![admin-termini-otvara-meni](../../screenshots/premestanje-termina-mobilni/07-admin-termini-otvara-meni.png)

## 8. Open the appointments list

The admin picks "Appointments" from the menu.

![admin-termini-bira-stavku](../../screenshots/premestanje-termina-mobilni/08-admin-termini-bira-stavku.png)

## 9. Search for the appointment

The admin searches the list by the customer's email to find the appointment that needs to move.

![admin-termini-pretraga](../../screenshots/premestanje-termina-mobilni/09-admin-termini-pretraga.png)

## 10. Open the appointment

On a phone the table scrolls sideways - the admin taps the details icon at the end of the row.

![admin-termini-otvaranje-rezultata](../../screenshots/premestanje-termina-mobilni/10-admin-termini-otvaranje-rezultata.png)

## 11. Reassign to a free employee

The admin picks a free employee from the dropdown and confirms the change.

![premestanje-na-slobodnog](../../screenshots/premestanje-termina-mobilni/11-premestanje-na-slobodnog.png)

## 12. Reopen the menu

The admin panel has its own menu behind a three-line button. The admin opens it and chooses the “Scheduling” group.

![admin-ponovo-otvara-meni](../../screenshots/premestanje-termina-mobilni/12-admin-ponovo-otvara-meni.png)

## 13. Reopen the appointments list

The admin opens the appointments list again.

![admin-ponovo-bira-stavku](../../screenshots/premestanje-termina-mobilni/13-admin-ponovo-bira-stavku.png)

## 14. Search again

The admin searches for the same customer again.

![admin-ponovo-pretraga](../../screenshots/premestanje-termina-mobilni/14-admin-ponovo-pretraga.png)

## 15. Reopen the appointment

On a phone the table scrolls sideways - the admin taps the details icon at the end of the row.

![admin-ponovo-otvaranje-rezultata](../../screenshots/premestanje-termina-mobilni/15-admin-ponovo-otvaranje-rezultata.png)

## 16. A busy employee isn't offered

In the dropdown, an employee already booked elsewhere at that exact time simply isn't listed - the system filtered them out in advance.

![zauzet-zaposleni-nije-ponudjen](../../screenshots/premestanje-termina-mobilni/16-zauzet-zaposleni-nije-ponudjen.png)
