# Creating a service (phone)

An administrator creates a new service in three phases: basic data with an image, variants and prices, extras. Recorded on a phone (390x844).

<video src="../../videos/kreiranje-usluge-mobilni/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/kreiranje-usluge-mobilni/01-admin-otvaranje-pocetne.png)

## 2. Open the menu

On a phone the menu is hidden behind the three-line button in the top right corner. We tap it.

![admin-login-otvara-meni](../../screenshots/kreiranje-usluge-mobilni/02-admin-login-otvara-meni.png)

## 3. Log in

We tap “Prijava”.

![admin-login-klik-prijava](../../screenshots/kreiranje-usluge-mobilni/03-admin-login-klik-prijava.png)

## 4. Admin logs in

The administrator types the email and password and logs in.

![admin-prijava](../../screenshots/kreiranje-usluge-mobilni/04-admin-prijava.png)

## 5. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-usluge-mobilni/05-admin-ulazak-otvara-nalog-meni.png)

## 6. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-usluge-mobilni/06-admin-ulazak-otvara-admin-panel.png)

## 7. “Katalog” menu

We open the “Katalog” group.

![admin-usluge-otvara-meni](../../screenshots/kreiranje-usluge-mobilni/07-admin-usluge-otvara-meni.png)

## 8. Usluge

We choose “Usluge”.

![admin-usluge-bira-stavku](../../screenshots/kreiranje-usluge-mobilni/08-admin-usluge-bira-stavku.png)

## 9. New service

We tap “Nova usluga”. A service is created in three phases, each on its own page.

![admin-usluge-klik-na-dodaj](../../screenshots/kreiranje-usluge-mobilni/09-admin-usluge-klik-na-dodaj.png)

## 10. Phase 1: basic data

We enter the service name and a short description.

![usluga-faza1-naziv](../../screenshots/kreiranje-usluge-mobilni/10-usluga-faza1-naziv.png)

## 11. Default duration

The default duration in minutes. Each variant can have its own.

![usluga-faza1-trajanje](../../screenshots/kreiranje-usluge-mobilni/11-usluga-faza1-trajanje.png)

## 12. Service image

We add the image and its description. The description is required for accessibility and search.

![usluga-faza1-slika](../../screenshots/kreiranje-usluge-mobilni/12-usluga-faza1-slika.png)

## 13. On to phase 2

We tap “Sačuvaj i nastavi”. We move on to the service variants.

![usluga-faza1-nastavak](../../screenshots/kreiranje-usluge-mobilni/13-usluga-faza1-nastavak.png)

## 14. Service variant

We add a variant: name, number of sessions, duration and price. One session is a regular appointment, several make a package.

![usluga-faza2-varijanta](../../screenshots/kreiranje-usluge-mobilni/14-usluga-faza2-varijanta.png)

## 15. On to phase 3

We tap “Sačuvaj i nastavi”. The last phase holds the extras.

![usluga-faza2-nastavak](../../screenshots/kreiranje-usluge-mobilni/15-usluga-faza2-nastavak.png)

## 16. Save and publish

Features, FAQ and recommended products are optional and can be added later. We tap “Sačuvaj” and the service is ready.

![usluga-faza3-objava](../../screenshots/kreiranje-usluge-mobilni/16-usluga-faza3-objava.png)
