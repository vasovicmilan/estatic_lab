# Forgotten password

A customer who forgot their password requests a link, sets a new one and logs in.

<video src="../../videos/zaboravljena-lozinka/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

We start on the site's home page.

![otvaranje-pocetne](../../screenshots/zaboravljena-lozinka/01-otvaranje-pocetne.png)

## 2. Log in

We click “Prijava” at the top of the page.

![login-klik-prijava](../../screenshots/zaboravljena-lozinka/02-login-klik-prijava.png)

## 3. Forgot your password?

On the login page we click “Zaboravili ste lozinku?”.

![zaboravljena-link](../../screenshots/zaboravljena-lozinka/03-zaboravljena-link.png)

## 4. Email address

We type the account's email address.

![zaboravljena-email](../../screenshots/zaboravljena-lozinka/04-zaboravljena-email.png)

## 5. Send the link

We click “Pošalji link”. A link to set a new password is emailed, and the message is the same whether or not the account exists.

![zaboravljena-slanje](../../screenshots/zaboravljena-lozinka/05-zaboravljena-slanje.png)

## 6. The link from the email

We open the link from the email. It is valid for a limited time.

![link-iz-mejla](../../screenshots/zaboravljena-lozinka/06-link-iz-mejla.png)

## 7. New password

We type the new password and repeat it (at least 8 characters).

![nova-lozinka](../../screenshots/zaboravljena-lozinka/07-nova-lozinka.png)

## 8. Save the password

We click “Sačuvaj lozinku”. A confirmation appears and we are taken back to the login.

![nova-lozinka-cuvanje](../../screenshots/zaboravljena-lozinka/08-nova-lozinka-cuvanje.png)

## 9. Log in

We log in with the new password.

![prijava-novom-lozinkom](../../screenshots/zaboravljena-lozinka/09-prijava-novom-lozinkom.png)
