# Employees - adding and how they are paid

An administrator makes an employee from an existing user: services, commission and the place for the SrediMe calendar.

<video src="../../videos/zaposleni-dodavanje/merged.en.burned.mp4" controls width="720"></video>

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/zaposleni-dodavanje/01-admin-otvaranje-pocetne.png)

## 2. Log in

We click “Prijava”.

![admin-login-klik-prijava](../../screenshots/zaposleni-dodavanje/02-admin-login-klik-prijava.png)

## 3. Admin logs in

The administrator types the email and password and logs in.

![admin-prijava](../../screenshots/zaposleni-dodavanje/03-admin-prijava.png)

## 4. Open the account menu

The admin clicks the dropdown with their name in the top right corner.

![admin-ulazak-otvara-nalog-meni](../../screenshots/zaposleni-dodavanje/04-admin-ulazak-otvara-nalog-meni.png)

## 5. Enter the admin panel

The admin chooses “Admin panel” from the menu, which opens the admin part of the site.

![admin-ulazak-otvara-admin-panel](../../screenshots/zaposleni-dodavanje/05-admin-ulazak-otvara-admin-panel.png)

## 6. “Tim” menu

We open the “Tim” group.

![admin-zaposleni-otvara-meni](../../screenshots/zaposleni-dodavanje/06-admin-zaposleni-otvara-meni.png)

## 7. Zaposleni

We choose “Zaposleni”.

![admin-zaposleni-bira-stavku](../../screenshots/zaposleni-dodavanje/07-admin-zaposleni-bira-stavku.png)

## 8. New employee

We click “Novi zaposleni”. An employee is made from an existing user account, not from scratch.

![admin-zaposleni-klik-na-dodaj](../../screenshots/zaposleni-dodavanje/08-admin-zaposleni-klik-na-dodaj.png)

## 9. Choose the user

We choose the user who becomes an employee.

![zaposleni-korisnik](../../screenshots/zaposleni-dodavanje/09-zaposleni-korisnik.png)

## 10. Services they perform

We pick the services the employee performs. The system offers them appointments only for those.

![zaposleni-usluge](../../screenshots/zaposleni-dodavanje/10-zaposleni-usluge.png)

## 11. How they are paid

A fixed salary or commission. For commission we enter the percentage, here 25%.

![zaposleni-isplata](../../screenshots/zaposleni-dodavanje/11-zaposleni-isplata.png)

## 12. The SrediMe calendar

This is where the employee's SrediMe ICS address goes. The system reads it periodically and blocks the time already booked there, so the same slot is never sold twice.

![zaposleni-sredime](../../screenshots/zaposleni-dodavanje/12-zaposleni-sredime.png)

## 13. Save

We save the employee. They set their working hours themselves in their account.

![zaposleni-cuvanje](../../screenshots/zaposleni-dodavanje/13-zaposleni-cuvanje.png)
