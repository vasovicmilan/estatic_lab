# Commission only becomes earned when an order completes

A partner's commission on an order stays "pending" through every intermediate status and only becomes "earned" (payout-eligible) once the admin marks the order fully completed - not merely delivered.

## 1. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/provizija-pri-zavrsetku-porudzbine/01-admin-prijava.png)

## 2. Open the account menu

The admin clicks the dropdown showing their name in the top-right corner.

![admin-ulazak-otvara-nalog-meni](../../screenshots/provizija-pri-zavrsetku-porudzbine/02-admin-ulazak-otvara-nalog-meni.png)

## 3. Enter the admin panel

The admin picks "Admin panel" from the menu, opening the site's admin area.

![admin-ulazak-otvara-admin-panel](../../screenshots/provizija-pri-zavrsetku-porudzbine/03-admin-ulazak-otvara-admin-panel.png)

## 4. Open the "Store" menu

The admin clicks the "Store" group in the admin menu.

![admin-porudzbine-otvara-meni](../../screenshots/provizija-pri-zavrsetku-porudzbine/04-admin-porudzbine-otvara-meni.png)

## 5. Open the orders list

The admin picks "Orders" from the menu.

![admin-porudzbine-bira-stavku](../../screenshots/provizija-pri-zavrsetku-porudzbine/05-admin-porudzbine-bira-stavku.png)

## 6. Search for the order

The admin searches by the customer's email.

![admin-porudzbine-pretraga](../../screenshots/provizija-pri-zavrsetku-porudzbine/06-admin-porudzbine-pretraga.png)

## 7. Open the order

The admin opens the order that has a partner commission pending on it.

![admin-porudzbine-otvaranje-rezultata](../../screenshots/provizija-pri-zavrsetku-porudzbine/07-admin-porudzbine-otvaranje-rezultata.png)

## 8. Mark as processing

The first status step - the commission stays pending.

![oznacavanje-u-obradi](../../screenshots/provizija-pri-zavrsetku-porudzbine/08-oznacavanje-u-obradi.png)

## 9. Mark as shipped

The second step - the commission is still pending.

![oznacavanje-poslato](../../screenshots/provizija-pri-zavrsetku-porudzbine/09-oznacavanje-poslato.png)

## 10. Mark as delivered

Even though it sounds final, "delivered" is NOT when the commission gets calculated - it's still pending.

![oznacavanje-dostavljeno](../../screenshots/provizija-pri-zavrsetku-porudzbine/10-oznacavanje-dostavljeno.png)

## 11. Mark as completed

Only this final status triggers the commission's promotion from "pending" to "earned" - now it's ready to be paid out to the partner.

![oznacavanje-zavrseno](../../screenshots/provizija-pri-zavrsetku-porudzbine/11-oznacavanje-zavrseno.png)
