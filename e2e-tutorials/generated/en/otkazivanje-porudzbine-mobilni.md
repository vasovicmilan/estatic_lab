# Cancelling an order (phone)

Unlike most other admin actions (usually a plain "are you sure?"), cancelling an order asks for a written reason - and automatically restores the product's stock behind the scenes. Recorded on a phone (390x844).

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/otkazivanje-porudzbine-mobilni/01-admin-otvaranje-pocetne.png)

## 2. Open the menu

On a phone the menu is hidden behind the three-line button in the top right corner. We tap it.

![admin-login-otvara-meni](../../screenshots/otkazivanje-porudzbine-mobilni/02-admin-login-otvara-meni.png)

## 3. Log in

We tap “Prijava”.

![admin-login-klik-prijava](../../screenshots/otkazivanje-porudzbine-mobilni/03-admin-login-klik-prijava.png)

## 4. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/otkazivanje-porudzbine-mobilni/04-admin-prijava.png)

## 5. Menu

On a phone the admin opens the main menu with the three-line button.

![admin-ulazak-otvara-nalog-meni](../../screenshots/otkazivanje-porudzbine-mobilni/05-admin-ulazak-otvara-nalog-meni.png)

## 6. Admin panel

In the “Admin” section they tap “Admin panel”.

![admin-ulazak-otvara-admin-panel](../../screenshots/otkazivanje-porudzbine-mobilni/06-admin-ulazak-otvara-admin-panel.png)

## 7. Open the "Store" menu

The admin panel has its own menu behind a three-line button. The admin opens it and chooses the “Store” group.

![admin-porudzbine-otvara-meni](../../screenshots/otkazivanje-porudzbine-mobilni/07-admin-porudzbine-otvara-meni.png)

## 8. Open the orders list

The admin picks "Orders" from the menu.

![admin-porudzbine-bira-stavku](../../screenshots/otkazivanje-porudzbine-mobilni/08-admin-porudzbine-bira-stavku.png)

## 9. Search for the order

The admin searches by the customer's email.

![admin-porudzbine-pretraga](../../screenshots/otkazivanje-porudzbine-mobilni/09-admin-porudzbine-pretraga.png)

## 10. Open the order

On a phone the table scrolls sideways - the admin taps the details icon at the end of the row.

![admin-porudzbine-otvaranje-rezultata](../../screenshots/otkazivanje-porudzbine-mobilni/10-admin-porudzbine-otvaranje-rezultata.png)

## 11. Open the cancellation dialog

The admin taps "Cancel order" - unlike other actions, this opens a form with a reason field, not a plain yes/no confirmation.

![otvaranje-modala-za-otkazivanje](../../screenshots/otkazivanje-porudzbine-mobilni/11-otvaranje-modala-za-otkazivanje.png)

## 12. Enter a reason

The admin enters a reason for the cancellation (the field is optional, but useful for record-keeping).

![unos-razloga](../../screenshots/otkazivanje-porudzbine-mobilni/12-unos-razloga.png)

## 13. Confirm the cancellation

The admin confirms - the order is cancelled, and the product's stock is automatically restored.

![potvrda-otkazivanja](../../screenshots/otkazivanje-porudzbine-mobilni/13-potvrda-otkazivanja.png)
