# Cancelling an order

Unlike most other admin actions (usually a plain "are you sure?"), cancelling an order asks for a written reason - and automatically restores the product's stock behind the scenes.

## 1. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/otkazivanje-porudzbine/01-admin-prijava.png)

## 2. Open the account menu

The admin clicks the dropdown showing their name in the top-right corner.

![admin-ulazak-otvara-nalog-meni](../../screenshots/otkazivanje-porudzbine/02-admin-ulazak-otvara-nalog-meni.png)

## 3. Enter the admin panel

The admin picks "Admin panel" from the menu.

![admin-ulazak-otvara-admin-panel](../../screenshots/otkazivanje-porudzbine/03-admin-ulazak-otvara-admin-panel.png)

## 4. Open the "Store" menu

The admin clicks the "Store" group in the admin menu.

![admin-porudzbine-otvara-meni](../../screenshots/otkazivanje-porudzbine/04-admin-porudzbine-otvara-meni.png)

## 5. Open the orders list

The admin picks "Orders" from the menu.

![admin-porudzbine-bira-stavku](../../screenshots/otkazivanje-porudzbine/05-admin-porudzbine-bira-stavku.png)

## 6. Search for the order

The admin searches by the customer's email.

![admin-porudzbine-pretraga](../../screenshots/otkazivanje-porudzbine/06-admin-porudzbine-pretraga.png)

## 7. Open the order

The admin opens the order that needs to be cancelled.

![admin-porudzbine-otvaranje-rezultata](../../screenshots/otkazivanje-porudzbine/07-admin-porudzbine-otvaranje-rezultata.png)

## 8. Open the cancellation dialog

The admin clicks "Cancel order" - unlike other actions, this opens a form with a reason field, not a plain yes/no confirmation.

![otvaranje-modala-za-otkazivanje](../../screenshots/otkazivanje-porudzbine/08-otvaranje-modala-za-otkazivanje.png)

## 9. Enter a reason

The admin enters a reason for the cancellation (the field is optional, but useful for record-keeping).

![unos-razloga](../../screenshots/otkazivanje-porudzbine/09-unos-razloga.png)

## 10. Confirm the cancellation

The admin confirms - the order is cancelled, and the product's stock is automatically restored.

![potvrda-otkazivanja](../../screenshots/otkazivanje-porudzbine/10-potvrda-otkazivanja.png)
