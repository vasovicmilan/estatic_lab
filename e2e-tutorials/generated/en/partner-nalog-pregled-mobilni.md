# Partner account - overview, copying your code and the catalog (phone)

On their account a partner sees how much they've earned, copies their referral link, reviews their commission and grabs ready-made links for every service, package and product from the sharing catalog. Every navigation step is shown - on a phone.

_Subtitles are burned into the video - no external .vtt file needed_

## 1. Home page

We start on the site's home page.

![otvaranje-pocetne](../../screenshots/partner-nalog-pregled-mobilni/01-otvaranje-pocetne.png)

## 2. Open the menu

On a phone the menu is hidden behind the three-line button in the top right corner. We tap it.

![login-otvara-meni](../../screenshots/partner-nalog-pregled-mobilni/02-login-otvara-meni.png)

## 3. Log in

In the menu we tap “Prijava”.

![login-klik-prijava](../../screenshots/partner-nalog-pregled-mobilni/03-login-klik-prijava.png)

## 4. Enter your login details

We enter the email and password and log in.

![unos-prijave](../../screenshots/partner-nalog-pregled-mobilni/04-unos-prijave.png)

## 5. Account menu

After logging in we open the menu again. At the bottom is a section with our name and account links - the page scrolls to it.

![portal-otvara-meni](../../screenshots/partner-nalog-pregled-mobilni/05-portal-otvara-meni.png)

## 6. Partner account

We tap “Partnerski nalog”.

![portal-bira-stavku](../../screenshots/partner-nalog-pregled-mobilni/06-portal-bira-stavku.png)

## 7. Partner account

“Moj partnerski nalog” opens. At the top it shows the commission rate on services and packages, and the one on shop products.

![otvaranje-partnerskog-naloga](../../screenshots/partner-nalog-pregled-mobilni/07-otvaranje-partnerskog-naloga.png)

## 8. Balance overview

Four cards: total earned, paid out, reserved (commission pending until the appointment or order is completed) and available for payout. Only earned commission can be paid out.

![pregled-stanja](../../screenshots/partner-nalog-pregled-mobilni/08-pregled-stanja.png)

## 9. Referral link

Here is the partner's referral link with their code, along with the discount the customer gets and what the code covers. If a partner has several codes, each has its own link.

![referalni-link](../../screenshots/partner-nalog-pregled-mobilni/09-referalni-link.png)

## 10. Copy the link

The “Kopiraj” button copies the link and briefly shows “Kopirano!”. Whenever someone visits the site through that link, the code is applied automatically.

![kopiranje-linka](../../screenshots/partner-nalog-pregled-mobilni/10-kopiranje-linka.png)

## 11. Commission tab

Tapping “Provizija” in the bottom bar switches to that tab. It lists every commission.

![tab-provizija](../../screenshots/partner-nalog-pregled-mobilni/11-tab-provizija.png)

## 12. Commission list

For each commission we see the source (appointment, package or order), base value, rate, amount and status. On a phone each item is a card.

![pregled-provizije](../../screenshots/partner-nalog-pregled-mobilni/12-pregled-provizije.png)

## 13. Filtering

Filters by status and source update the list as soon as a value is chosen. “Na čekanju” shows commission that isn't earned yet.

![filter-provizije](../../screenshots/partner-nalog-pregled-mobilni/13-filter-provizije.png)

## 14. Sharing catalog

Tapping “Katalog” in the bottom bar switches to that tab. It lists services, packages and products, each with a ready link that already contains the partner's code.

![tab-katalog](../../screenshots/partner-nalog-pregled-mobilni/14-tab-katalog.png)

## 15. Searching the catalog

Search finds an item by name across all three sections at once.

![pretraga-kataloga](../../screenshots/partner-nalog-pregled-mobilni/15-pretraga-kataloga.png)

## 16. Copy an item's link

The link goes straight to that service or package with the code already applied. It's copied with the same button as the main link.

![kopiranje-iz-kataloga](../../screenshots/partner-nalog-pregled-mobilni/16-kopiranje-iz-kataloga.png)

## 17. Products in the catalog

Products only appear if the code includes a shop-product discount, and only those the code actually applies to. That way a partner never shares a link that wouldn't give a discount.

![proizvodi-u-katalogu](../../screenshots/partner-nalog-pregled-mobilni/17-proizvodi-u-katalogu.png)

## 18. Payouts tab

Tapping “Isplate” in the bottom bar switches to that tab. Here the partner sees all their payout requests. There are none yet.

![tab-isplate](../../screenshots/partner-nalog-pregled-mobilni/18-tab-isplate.png)

## 19. Back to overview

Tapping “Pregled” in the bottom bar switches to that tab. That takes us back to the account's main screen.

![tab-pregled](../../screenshots/partner-nalog-pregled-mobilni/19-tab-pregled.png)
