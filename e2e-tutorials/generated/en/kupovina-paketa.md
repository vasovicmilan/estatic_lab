# Buying a session package

Packages have no self-checkout - an admin manually assigns one to a customer, who then spends sessions from it through the ordinary booking flow, at no extra charge.

## 1. Register

The customer registers first - an account has to exist before an admin can assign them a package.

![registracija](../../screenshots/kupovina-paketa/01-registracija.png)

## 2. Log in

The customer logs into their new account.

![prijava](../../screenshots/kupovina-paketa/02-prijava.png)

## 3. Admin logs in

The admin logs in to assign a package to the customer.

![admin-prijava](../../screenshots/kupovina-paketa/03-admin-prijava.png)

## 4. Open the account menu

The admin clicks the dropdown showing their name in the top-right corner.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kupovina-paketa/04-admin-ulazak-otvara-nalog-meni.png)

## 5. Enter the admin panel

The admin picks "Admin panel" from the menu, opening the site's admin area.

![admin-ulazak-otvara-admin-panel](../../screenshots/kupovina-paketa/05-admin-ulazak-otvara-admin-panel.png)

## 6. Open the "Catalog" menu

The admin clicks the "Catalog" group in the admin menu.

![admin-paketi-otvara-meni](../../screenshots/kupovina-paketa/06-admin-paketi-otvara-meni.png)

## 7. Open purchased packages

The admin picks "Purchased packages" from the menu.

![admin-paketi-bira-stavku](../../screenshots/kupovina-paketa/07-admin-paketi-bira-stavku.png)

## 8. Assign a new package

The admin clicks "Assign package", opening the assignment form.

![admin-paketi-klik-na-dodaj](../../screenshots/kupovina-paketa/08-admin-paketi-klik-na-dodaj.png)

## 9. Assign the package

The admin confirms the assignment - a 3-session package is now on the customer's account, ready to use.

![admin-dodeljuje-paket](../../screenshots/kupovina-paketa/09-admin-dodeljuje-paket.png)

## 10. Book the service

The customer opens the page for the service their package covers and selects a variant.

![otvaranje-stranice-usluge](../../screenshots/kupovina-paketa/10-otvaranje-stranice-usluge.png)

## 11. Pick a time slot

The customer picks a date and an available slot, same as an ordinary booking.

![izbor-datuma-i-termina](../../screenshots/kupovina-paketa/11-izbor-datuma-i-termina.png)

## 12. Paying from the package

The system recognizes the customer has a usable package for this exact service - the "pay from package" option is checked automatically, showing how many sessions remain.

![placanje-iz-paketa](../../screenshots/kupovina-paketa/12-placanje-iz-paketa.png)

## 13. Enter contact details

The customer enters a phone number before confirming.

![unos-kontakt-podataka](../../screenshots/kupovina-paketa/13-unos-kontakt-podataka.png)

## 14. Confirm the booking

The appointment is booked with no charge at all - the price is covered by the package.

![potvrda-zakazivanja](../../screenshots/kupovina-paketa/14-potvrda-zakazivanja.png)

## 15. Open the "Scheduling" menu

The admin clicks the "Scheduling" group in the admin menu.

![admin-termini-otvara-meni](../../screenshots/kupovina-paketa/15-admin-termini-otvara-meni.png)

## 16. Open the appointments list

The admin picks "Appointments" from the menu.

![admin-termini-bira-stavku](../../screenshots/kupovina-paketa/16-admin-termini-bira-stavku.png)

## 17. Search for the appointment

The admin searches the list by the customer's email.

![admin-termini-pretraga](../../screenshots/kupovina-paketa/17-admin-termini-pretraga.png)

## 18. Open the appointment

The admin opens the new appointment from the search results.

![admin-termini-otvaranje-rezultata](../../screenshots/kupovina-paketa/18-admin-termini-otvaranje-rezultata.png)

## 19. Admin confirms the appointment

The admin confirms the appointment - the session is now reserved from the package, but not yet spent.

![admin-potvrdjuje-termin](../../screenshots/kupovina-paketa/19-admin-potvrdjuje-termin.png)

## 20. Admin completes the appointment

Once the service has actually been delivered, the admin marks it completed - only now is the session from the package actually spent.

![admin-zavrsava-termin](../../screenshots/kupovina-paketa/20-admin-zavrsava-termin.png)
