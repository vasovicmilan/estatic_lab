# Buying a session package

Packages have no self-checkout - an admin manually assigns one to a customer, who then spends sessions from it through the ordinary booking flow, at no extra charge.

## 1. Home page

We start on the site's home page.

![otvaranje-pocetne](../../screenshots/kupovina-paketa/01-otvaranje-pocetne.png)

## 2. Registration

We click “Registracija” and the account form opens.

![registracija-klik-registracija](../../screenshots/kupovina-paketa/02-registracija-klik-registracija.png)

## 3. Register

The customer registers first - an account has to exist before an admin can assign them a package.

![registracija](../../screenshots/kupovina-paketa/03-registracija.png)

## 4. Log in

The customer logs into their new account.

![prijava](../../screenshots/kupovina-paketa/04-prijava.png)

## 5. Home page

The administrator starts on the site's home page.

![admin-otvaranje-pocetne](../../screenshots/kupovina-paketa/05-admin-otvaranje-pocetne.png)

## 6. Log in

We click “Prijava”.

![admin-login-klik-prijava](../../screenshots/kupovina-paketa/06-admin-login-klik-prijava.png)

## 7. Admin logs in

The admin logs in to assign a package to the customer.

![admin-prijava](../../screenshots/kupovina-paketa/07-admin-prijava.png)

## 8. Open the account menu

The admin clicks the dropdown with their name in the top right corner.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kupovina-paketa/08-admin-ulazak-otvara-nalog-meni.png)

## 9. Enter the admin panel

The admin chooses “Admin panel” from the menu, which opens the admin part of the site.

![admin-ulazak-otvara-admin-panel](../../screenshots/kupovina-paketa/09-admin-ulazak-otvara-admin-panel.png)

## 10. Open the "Catalog" menu

The admin clicks the "Catalog" group in the admin menu.

![admin-paketi-otvara-meni](../../screenshots/kupovina-paketa/10-admin-paketi-otvara-meni.png)

## 11. Open purchased packages

The admin picks "Purchased packages" from the menu.

![admin-paketi-bira-stavku](../../screenshots/kupovina-paketa/11-admin-paketi-bira-stavku.png)

## 12. Assign a new package

The admin clicks "Assign package", opening the assignment form.

![admin-paketi-klik-na-dodaj](../../screenshots/kupovina-paketa/12-admin-paketi-klik-na-dodaj.png)

## 13. Assign the package

The admin confirms the assignment - a 3-session package is now on the customer's account, ready to use.

![admin-dodeljuje-paket](../../screenshots/kupovina-paketa/13-admin-dodeljuje-paket.png)

## 14. Book an appointment

We click the “Zakažite termin” button - it leads straight to the list of services.

![nav-zakazite-termin](../../screenshots/kupovina-paketa/14-nav-zakazite-termin.png)

## 15. Choosing a service

In the list of services we click the service the package covers. Its page shows the description and the variants.

![otvaranje-stranice-usluge](../../screenshots/kupovina-paketa/15-otvaranje-stranice-usluge.png)

## 16. Choosing a variant

We click “Zakaži” on the variant we want and move on to choosing a time.

![izbor-varijante-usluge](../../screenshots/kupovina-paketa/16-izbor-varijante-usluge.png)

## 17. Choosing a date

We choose a date - the field is highlighted. The system shows the free slots for that day, based on the employees' working hours.

![izbor-datuma](../../screenshots/kupovina-paketa/17-izbor-datuma.png)

## 18. Choosing a time slot

We click the time we want.

![izbor-termina](../../screenshots/kupovina-paketa/18-izbor-termina.png)

## 19. Paying from the package

The system recognizes the customer has a usable package for this exact service - the "pay from package" option is checked automatically, showing how many sessions remain.

![placanje-iz-paketa](../../screenshots/kupovina-paketa/19-placanje-iz-paketa.png)

## 20. Enter contact details

The customer enters a phone number before confirming.

![unos-kontakt-podataka](../../screenshots/kupovina-paketa/20-unos-kontakt-podataka.png)

## 21. Confirm the booking

The appointment is booked with no charge at all - the price is covered by the package.

![potvrda-zakazivanja](../../screenshots/kupovina-paketa/21-potvrda-zakazivanja.png)

## 22. Open the “Zakazivanje” menu

The admin clicks the “Zakazivanje” group in the admin menu to see its items.

![admin-termini-otvara-meni](../../screenshots/kupovina-paketa/22-admin-termini-otvara-meni.png)

## 23. Open the appointment list

The admin chooses “Termini” - the list of all appointments opens.

![admin-termini-bira-stavku](../../screenshots/kupovina-paketa/23-admin-termini-bira-stavku.png)

## 24. Search for the appointment

The admin searches the list by the customer's email to find the new appointment quickly.

![admin-termini-pretraga](../../screenshots/kupovina-paketa/24-admin-termini-pretraga.png)

## 25. Open the appointment from the results

The admin opens the appointment's details with the icon in the table row.

![admin-termini-otvaranje-rezultata](../../screenshots/kupovina-paketa/25-admin-termini-otvaranje-rezultata.png)

## 26. Admin confirms the appointment

The admin confirms the appointment - the session is now reserved from the package, but not yet spent.

![admin-potvrdjuje-termin](../../screenshots/kupovina-paketa/26-admin-potvrdjuje-termin.png)

## 27. Admin completes the appointment

Once the service has actually been delivered, the admin marks it completed - only now is the session from the package actually spent.

![admin-zavrsava-termin](../../screenshots/kupovina-paketa/27-admin-zavrsava-termin.png)
