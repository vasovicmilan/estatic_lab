# Creating a blog post

The admin writes and publishes a new blog post - a title, a short excerpt, body text through a block-based editor, and a required cover image.

## 1. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/kreiranje-blog-posta/01-admin-prijava.png)

## 2. Open the account menu

The admin clicks the dropdown showing their name.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-blog-posta/02-admin-ulazak-otvara-nalog-meni.png)

## 3. Enter the admin panel

The admin picks "Admin panel".

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-blog-posta/03-admin-ulazak-otvara-admin-panel.png)

## 4. Open the "Content and marketing" menu

The admin clicks the "Content and marketing" group.

![admin-blog-otvara-meni](../../screenshots/kreiranje-blog-posta/04-admin-blog-otvara-meni.png)

## 5. Open the blog

The admin picks "Blog" from the menu.

![admin-blog-bira-stavku](../../screenshots/kreiranje-blog-posta/05-admin-blog-bira-stavku.png)

## 6. New post

The admin clicks "New post".

![admin-blog-klik-na-dodaj](../../screenshots/kreiranje-blog-posta/06-admin-blog-klik-na-dodaj.png)

## 7. Enter the title and excerpt

The admin enters the title and a short excerpt shown in previews.

![unos-naslova-i-opisa](../../screenshots/kreiranje-blog-posta/07-unos-naslova-i-opisa.png)

## 8. Add a paragraph

The admin adds a text block - the editor is block-based, each type has its own fields.

![dodavanje-pasusa](../../screenshots/kreiranje-blog-posta/08-dodavanje-pasusa.png)

## 9. Choose the status

The admin selects "Published" - the post becomes publicly visible immediately.

![izbor-statusa](../../screenshots/kreiranje-blog-posta/09-izbor-statusa.png)

## 10. Upload a cover image

A cover image is required - the admin uploads one and enters alt text.

![otpremanje-naslovne-slike](../../screenshots/kreiranje-blog-posta/10-otpremanje-naslovne-slike.png)

## 11. Save the post

The admin saves the post - it's immediately available on the public blog.

![cuvanje-posta](../../screenshots/kreiranje-blog-posta/11-cuvanje-posta.png)
