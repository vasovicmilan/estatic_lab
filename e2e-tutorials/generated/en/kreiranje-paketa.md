# Creating a package

The admin creates a new session package - selecting an existing service, entering a price, and setting a required image, all before the package is ready to be assigned to customers.

## 1. Admin logs in

The admin logs into their account.

![admin-prijava](../../screenshots/kreiranje-paketa/01-admin-prijava.png)

## 2. Open the account menu

The admin clicks the dropdown showing their name.

![admin-ulazak-otvara-nalog-meni](../../screenshots/kreiranje-paketa/02-admin-ulazak-otvara-nalog-meni.png)

## 3. Enter the admin panel

The admin picks "Admin panel".

![admin-ulazak-otvara-admin-panel](../../screenshots/kreiranje-paketa/03-admin-ulazak-otvara-admin-panel.png)

## 4. Open the "Catalog" menu

The admin clicks the "Catalog" group.

![admin-paketi-otvara-meni](../../screenshots/kreiranje-paketa/04-admin-paketi-otvara-meni.png)

## 5. Open packages

The admin picks "Packages" from the menu.

![admin-paketi-bira-stavku](../../screenshots/kreiranje-paketa/05-admin-paketi-bira-stavku.png)

## 6. New package

The admin clicks "New package".

![admin-paketi-klik-na-dodaj](../../screenshots/kreiranje-paketa/06-admin-paketi-klik-na-dodaj.png)

## 7. Enter basic details

The admin enters the package's name and description.

![unos-osnovnih-podataka](../../screenshots/kreiranje-paketa/07-unos-osnovnih-podataka.png)

## 8. Add a service to the package

The admin adds a row, picks the exact service and variant, and enters how many sessions the package includes.

![dodavanje-usluge-u-paket](../../screenshots/kreiranje-paketa/08-dodavanje-usluge-u-paket.png)

## 9. Enter the price

The admin enters the package's total price - usually lower than the sum of individual sessions.

![unos-cene](../../screenshots/kreiranje-paketa/09-unos-cene.png)

## 10. Upload an image

An image is required for a package - the admin uploads one and enters alt text.

![otpremanje-slike](../../screenshots/kreiranje-paketa/10-otpremanje-slike.png)

## 11. Save the package

The admin saves the package - it's now ready to be assigned to customers.

![cuvanje-paketa](../../screenshots/kreiranje-paketa/11-cuvanje-paketa.png)
